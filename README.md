# Priority Flow

A calm mobile-first activity recommendation app built with Expo, React Native Web, TypeScript, NativeWind, Zustand, local browser storage, and Reanimated.

## Run it

```bash
npm install
npm run web
```

This starts the browser version locally.

## Build for sharing

```bash
npm run build:web
```

The static web build is exported to `dist`, which can be deployed to simple static hosting.

## Helpful commands

```bash
npm run web
npm run build:web
npm run typecheck
```
